# Explore Naija

This rebuilt project follows the supplied Explore Naija site plan and homepage wireframes.

## Pages
- `index.html` — homepage with hero, Explore Destinations button, featured destinations, and wireframe-style footer.
- `destinations.html` — destination cards, category filter, and localStorage favourites.
- `plan.html` — trip-planning form with validation and localStorage.
- `references.html` — references and image-credit page.

## Design tokens from the site plan
- Deep Green: `#003D32`
- Fresh Green: `#009B55`
- Cream: `#F5F3EA`
- Dark Teal: `#123C35`
- Poppins for headings/navigation; Roboto for body text.
- Large-screen breakpoint: `@media screen and (min-width: 750px)`.

## Images required
Copy your actual `tourism-logo.webp` and `tourism-landscape.webp` into `images/`, and add optimized/licensed files named:
`olumirin-waterfall.webp`, `lekki-conservation.webp`, `olumo-rock.webp`, `obudu-mountain.webp`, `yankari-reserve.webp`, `tarkwa-bay.webp`, and `nigeria-culture.webp`.
The ZIP contains website code, not those image assets. Add exact source URLs, creators, and licences for each image to `references.html` before submitting.

The form and favourites work in the browser using localStorage. The trip form does not send email or submit to a server.
